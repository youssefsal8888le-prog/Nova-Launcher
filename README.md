Nova Launcher es un lanzador que te permite jugar a Minecraft: Java Edition en tus dispositivos Android e iOS. Basado en el motor original de PojavLauncher, esta versión incluye personalizaciones visuales y mejoras de rendimiento.

## 🚀 Características principales

* **Compatibilidad Total**: Ejecuta casi todas las versiones de Minecraft, desde las clásicas hasta las más recientes (1.21+).
* **Soporte de Mods**: Compatible con Forge y Fabric para que lleves tus mods favoritos a todas partes.
* **Interfaz Nova**: Iconos y menús rediseñados para una experiencia más limpia.
* **Alto Rendimiento**: Optimizado para reducir el consumo de batería y mejorar los FPS.

## 🛠️ Instalación y Construcción

Si quieres compilar tu propia versión de **Nova Launcher**, sigue estos pasos:

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/youssefsal8888le-prog/Nova-Launcher.git
   ```

2. **Compilar el APK**:
   ```bash
   ./gradlew :app_pojavlauncher:assembleDebug
   ```

El archivo APK resultante estará en `app_pojavlauncher/build/outputs/apk/debug/`.
